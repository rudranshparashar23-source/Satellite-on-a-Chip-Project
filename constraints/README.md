# Constraints

This folder is intended to store FPGA constraint files used during hardware implementation.

## Constraint Information

The SAToC project was implemented on the **PYNQ-Z2** development board using **AMD Vivado Design Suite 2025.2**.

The hardware design was validated through synthesis, implementation, timing analysis, and bitstream generation within Vivado.

The required pin assignments and timing constraints were configured as part of the Vivado project during implementation.

## Target Device

- Board: PYNQ-Z2
- FPGA Device: Xilinx Zynq-7000 XC7Z020-1CLG400C

Future revisions may include standalone XDC constraint files.
