# Documentation

This directory contains the technical documentation for the Satellite-on-a-Chip (SAToC) project.

## Documents

### Project_Overview.md
Provides an overview of the project objectives, scope, and implemented features.

### FPGA_Platform_Selection.md
Describes the selection of the PYNQ-Z2 development board and explains the design decisions behind the chosen FPGA platform.

### System_Architecture.md
Explains the overall SAToC architecture, including the NEORV32 RISC-V processor, OBDH, TT&C, EPS, Memory Controller, AXI interconnect, and system integration.

### Vivado_Implementation.md
Documents the implementation flow using AMD Vivado Design Suite 2025.2, including:
- Block Design
- RTL Integration
- Synthesis
- Implementation
- Timing Analysis
- Bitstream Generation

## Development Environment

- **IDE:** AMD Vivado Design Suite 2025.2
- **Target Board:** PYNQ-Z2
- **FPGA Device:** Xilinx Zynq-7000 XC7Z020-1CLG400C
- **Language:** VHDL
